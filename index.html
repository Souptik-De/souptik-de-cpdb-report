Overview

From broken print jobs to a complete options model

The work follows a clear arc: make the projects testable, fix the print path, make it portable across sandboxes, then extend the API, harden memory safety, and cover driver-based queues.

Between February 10 and November 16, 2026, Souptik De authored 25 merged commits through 24 pull requests across cpdb-backend-cups and cpdb-libs. A 25th PR, #54, was closed without merge and superseded by #55.

The first phase builds the safety net: GitHub Actions build/test and CodeQL workflows in both repositories, a C test harness, and unit coverage for URI parsing. The second phase repairs print submission itself — stack-corrupting buffer sizes, an accept() deadlock, uninitialised socket paths, missing environment handling, opaque D-Bus errors, and a 401 failure under authenticated CUPS policies.

The largest architectural change is print FD passing: the frontend now tries printFd first, which works across Snap/container boundaries, and falls back to the legacy socket path only for older backends. Later work adds a GMutex around printer/dialog state, delivers the GetAllCapabilities model, and introduces translation-quality tags with a 3-way capability merge.

The late-summer phase is about quality: translation-path and option-path leak fixes, CUPS 3.x shim repairs, a cppcheck cleanup, and a portable find_cupsd() helper that lets make check pass on Arch usrmerge and restrictive-permission installs.

The newest phase, merged in November, extends the option model to CUPS 2.x driver-based queues. Vendor PPD keywords are fetched over IPP, localized by libcups, merged with their IPP equivalents where both describe the same concept, and sent in both forms at job time — so settings that never surfaced as IPP attributes finally reach the print dialog.

Nov 16backend#81

Vendor PPD options reach driver-based queues

Fetches the queue PPD over IPP with cupsGetPPD2(), localizes it with ppdOpenFile() and ppdLocalize(), and merges vendor keywords that duplicate IPP attributes (ColorModel, Duplex, Resolution, InputSlot, MediaType, OutputBin, cupsPrintQuality). Adds integration coverage plus unit tests for the mapping and dual-form submission, and fixes issue #63, where the GTK4 print dialog did not load a driver queue's filter settings.
