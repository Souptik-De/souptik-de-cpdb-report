# Souptik De — CPDB Stack Contribution Report

A single-page HTML report of Souptik De's contributions to the OpenPrinting CPDB
stack (`cpdb-backend-cups` and `cpdb-libs`).

Open `index.html` directly in a browser, or serve the folder with:

```bash
python3 -m http.server 8000
```

The site is published at [cpdb.souptik.xyz](https://cpdb.souptik.xyz).

Git history keeps the original October 2026 version as the first commit and the
updated November 2026 version as the second.
